## 📝 使用指南

### 1. Web界面操作
1. 登录后台管理系统
2. 导航至 "任务管理" → "数据库备份与恢复"
3. 使用以下功能：
   - **立即备份**: 点击"立即备份数据库"按钮
   - **查看备份**: 在备份文件列表中查看所有备份
   - **预览内容**: 点击"预览"按钮查看备份内容
   - **下载备份**: 点击"下载"按钮获取备份文件
   - **恢复数据**: 点击"恢复"按钮从备份恢复
   - **删除备份**: 点击"删除"按钮移除备份文件
   - **清理旧备份**: 批量清理超出保留数量的旧备份

### 2. 定时备份配置
1. 点击"配置定时任务"按钮
2. 配置每日备份：
   - 启用/禁用开关
   - 设置执行时间（默认02:00）
   - 设置保留天数（默认7天）
3. 配置每周备份：
   - 启用/禁用开关
   - 选择执行星期（默认周日）
   - 设置执行时间（默认03:00）
   - 设置保留周数（默认4周）
4. 点击"保存配置"完成设置

### 3. 命令行操作
```powershell
# 查看调度器状态
python app_backup_scheduler.py status

# 启动独立调度器服务
python app_backup_scheduler.py start

# 执行测试备份
python app_backup_scheduler.py test

# 运行系统测试
python test_backup_system.py test
```

## 🔧 技术实现

### 核心技术栈
- **后端框架**: Flask + Plotly Dash
- **数据库**: MySQL 5.7/8.0
- **备份工具**: mysqldump
- **任务调度**: APScheduler
- **文件压缩**: Python zipfile

## 🚨 注意事项

### 重要提醒
1. **数据安全**: 恢复操作会覆盖现有数据，操作前会自动创建安全备份
2. **存储空间**: 定期清理旧备份以释放存储空间
3. **权限要求**: 确保MySQL用户具有必要的备份和恢复权限
4. **网络连接**: 备份和恢复操作需要稳定的数据库连接
5. **系统资源**: 大型数据库备份可能消耗较多系统资源

### 故障排除
- **mysqldump命令不可用**: 确保MySQL客户端已正确安装
- **权限不足**: 检查数据库用户权限设置
- **存储空间不足**: 清理旧备份或扩展存储空间
- **网络连接问题**: 检查数据库连接配置
