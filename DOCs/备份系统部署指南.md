# 🏛️ 海外文物后台管理系统 - 备份系统部署指南

## 📋 部署检查清单

### 1. 核心文件确认
- ✅ `backup_utils_enhanced.py` - 增强版备份工具
- ✅ `backup_scheduler.py` - 备份调度器
- ✅ `app_backup_scheduler.py` - 独立调度器服务
- ✅ `db_backup_mgmt.py` - UI界面
- ✅ `db_backup_mgmt_c.py` - 回调函数
- ✅ `download_routes.py` - 下载路由

### 2. 系统要求
- ✅ MySQL客户端工具 (mysqldump, mysql)
- ✅ Python 3.7+
- ✅ 所需Python包：APScheduler, zipfile, pathlib

### 3. 配置确认
- ✅ 数据库连接配置 (`dashgo_conf.py`)
- ✅ 备份目录自动创建
- ✅ 调度器配置文件 (`backup_schedule.json`)

## 🚀 启动步骤

### 启动主应用
```bash
cd src
python app.py
```

### 启动独立备份调度器（可选）
```bash
cd src
python app_backup_scheduler.py start
```

### 查看调度器状态
```bash
python app_backup_scheduler.py status
```

```bash
python app_backup_scheduler.py test
```

- 确保 `SqlDbConf` 类包含正确的数据库连接信息

## 🚨 故障排除

### 常见问题

1. **mysqldump 命令不存在**
   - 安装MySQL客户端工具
   - 确保mysqldump在系统PATH中

2. **权限不足**
   - 确保数据库用户有备份权限
   - 确保备份目录有写入权限

3. **调度器无法启动**
   - 检查端口占用
   - 检查配置文件格式
   - 查看日志文件

### 日志查看
- 应用日志：`src/DashGo.log`
- 调度器日志：控制台输出或系统日志
