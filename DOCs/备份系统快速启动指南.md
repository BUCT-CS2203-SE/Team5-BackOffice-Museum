# 🚀 备份系统快速启动指南

## 🎯 5分钟快速上手

### 1️⃣ 立即体验备份功能
```powershell
# 1. 进入项目目录
cd C:\Users\WPP_JKW\Team5-BackOffice-Museum\src

# 2. 运行快速测试（验证所有功能）
python test_backup_system.py test

# 3. 查看调度器状态
python app_backup_scheduler.py status
```

### 2️⃣ Web界面操作
1. **启动主应用**
   ```powershell
   python app.py
   ```

2. **访问备份管理页面**
   - 打开浏览器，访问系统主页
   - 登录后台管理系统
   - 导航至：`任务管理` → `数据库备份与恢复`

3. **执行首次备份**
   - 点击 `立即备份数据库` 按钮
   - 等待备份完成（约10-30秒）
   - 在备份列表中查看新创建的备份

### 3️⃣ 常用操作

#### 📥 手动备份
- 点击 `立即备份数据库` → 等待完成 → 查看备份列表

#### 👀 预览备份内容
- 在备份列表中点击 `预览` → 查看SQL内容前100行

#### 📤 下载备份文件
- 在备份列表中点击 `下载` → 在新窗口中点击下载链接

#### ⚙️ 配置定时备份
- 点击 `配置定时任务` → 设置每日/每周备份计划 → 保存配置

#### 🔄 从备份恢复
- 选择备份文件 → 点击 `恢复` → 确认操作（⚠️危险操作）

#### 🗑️ 清理旧备份
- 点击 `清理旧备份` → 设置保留数量 → 确认清理

### 4️⃣ 启动定时备份服务
```powershell
# 启动独立的定时备份服务（后台运行）
python app_backup_scheduler.py start
```

## 🔧 故障快速排除

### 问题1：mysqldump命令不可用
```powershell
# 解决方案：安装MySQL客户端工具
# 1. 下载MySQL Installer
# 2. 选择安装MySQL Client
# 3. 确保mysql和mysqldump在系统PATH中
```

### 问题2：备份失败
```powershell
# 检查步骤：
# 1. 验证数据库连接：检查config/dashgo.ini配置
# 2. 检查权限：确保数据库用户有SELECT权限
# 3. 检查磁盘空间：确保有足够存储空间
# 4. 查看日志：检查DashGo.log文件
```

### 问题3：调度器无法启动
```powershell
# 检查调度器状态
python app_backup_scheduler.py status

# 查看配置文件
# config/backup_schedule.json
```
